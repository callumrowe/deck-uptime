## Configuration

Everything lives in [`.upptimerc.yml`](./.upptimerc.yml). The workflows under
`.github/workflows/` are generated from it by the Upptime template and are
overwritten weekly — change the config, not the workflows.

Required repository secrets:

| Secret                           | Purpose                                                                                                                                                         |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GH_PAT`                         | Fine-grained token with read/write on Actions, Contents, Issues and Workflows for this repository. The workflows commit results and open outage issues with it. |
| `NOTIFICATION_SLACK`             | The literal string `true`.                                                                                                                                      |
| `NOTIFICATION_SLACK_WEBHOOK_URL` | Incoming Webhook for Deck's uptime channel.                                                                                                                     |

The uptime channel is deliberately its own channel, separate from Deck's sync,
infra, backups and error channels. Muting the chatty one must never mute this
one.
